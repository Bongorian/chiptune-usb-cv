# v0.10 起動と復旧

更新時は専用基板用の[chiptune-v0.10.0-alpha.uf2](dist/chiptune-v0.10.0-alpha.uf2)を使用します。

1. 電源を外し、−と＋を押しながらUSB接続します。`RPI-RP2`が見えたらボタンを離します。
2. UF2をコピーします。ドライブが消えたら、ボタンを離してUSBを抜き差しします。
3. USB MIDI認識とOLEDを個別に確認します。Menu → SYSTEMの見出しはV0.10です。
4. MIDI ch1またはPLAY / SOUND → AUDITION A2で確認します。

ファームウェアから更新モードへ入れない場合は、電源を外してJP1（BOOT）を短絡しUSB接続します。認識後に短絡を外します。JP2はRESETです。通常の更新にフラッシュ全消去は不要です。USB UPDATEはMenu → SYSTEMにもあります。

OKだけを押してUSB接続すると保存を無視し、初期値で起動します。`DEFAULTS (RAM)`と表示します。これは保存領域を消さず、書き込みません。通常起動へ戻せば有効なv10保存を再読込します。

**v0.10は旧保存形式を移行しません。** 旧版のUSER音色・CV校正・明るさは読み込みません。未知の形式やCRC不正は初期値へフォールバックし、起動中に消去・再保存しません。新版で明示的に保存すると2バンクの一方を上書きします。必要な旧版データはその前に退避してください。

末尾64 KiBをリンカーで予約し、SDKの物理フラッシュ容量は2 MiBを維持します。過去の起動停止原因だった容量制限の混同と、起動時の自動保存はありません。v10のARM起動試験では空／有効v10／破損v10／旧形式／OK保持を実行し、USB初期化順と起動中のフラッシュ書込0回を確認します。実際のUSB列挙・フラッシュ保持・表示は[実機確認](BRINGUP.md)が必要です。
